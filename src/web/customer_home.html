Agentic

How Agentic Retrieval Works

1. Your question is sent to gpt-5.2 for query planning.
2. The LLM decomposes complex questions into sub-queries.
3. Sub-queries run in parallel across multiple knowledge sources:
• ks-enterprise-index — Azure AI Search (68 docs)
• ks-enterprise-docs — Azure Blob Storage (28 docs)
4. Results are aggregated, deduplicated, and returned with source citations.
vs. Basic Search: Agentic Retrieval adds LLM reasoning on top — better for complex, multi-faceted questions.
